排版台 · 使用说明

一个纯粹的排版工具：页面各有布局，素材全站共用。
上传素材
左侧「上传图片」，可多选。透明 PNG / WebP / JPG 均可，存一次，所有页面共用。
添加到画布
点一下素材缩略图，图片出现在当前页面中央。
移动
直接拖动画布上的元素。
缩放
拖八个控制点。角点=等比，边中点=单向拉伸；按住 Shift 角点可自由拉伸。
旋转
拖选区上方的圆点；按住 Shift 吸附到 15° 整数倍。
图层顺序
右侧图层列表直接上下拖动。越靠上，画布里越靠前。
隐藏 / 锁定
图层条上的眼睛与锁。锁定后不能移动、缩放、删除。
删除
选中元素按 Delete，或点图层上的垃圾桶。只删画布元素，不删素材库里的原图。
复制
Ctrl/⌘ + D 复制选中元素。
微移
方向键 1px，Shift + 方向键 10px。
撤销 / 重做
Ctrl/⌘ + Z；Ctrl/⌘ + Shift + Z 或 Ctrl/⌘ + Y。
页面
顶部标签切换；双击标签改名；标签上的 × 删除页面（至少保留一页）。
预览
点「预览」进入纯净视图，Esc 退出。
导入 / 导出
导出为一个 JSON 文件（含全部素材与页面）；导入可完整还原项目。
自动保存：每次操作后自动存入本浏览器的本地存储，刷新不会丢。
多窗口同步：双击同一个 HTML 文件打开两个窗口（或用同一地址开两个标签页），任一窗口的改动会在约 1 秒内同步到另一个。别用「另存为」存成两份不同路径的文件，那会是两份独立数据。
数据安全：数据只在这台电脑的浏览器里，不上传任何服务器。清理浏览器站点数据会清掉项目，重要版本请用「导出」备份。
